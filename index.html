Konfigurasi Supabase & Matriks Pulau

Struktur tabel yang dipakai

Aplikasi membaca reports termasuk npulau. Nilai pulau harus salah satu dari: SUMATERA, KALIMANTAN, JAWA, BALI NUSRA, SULAWESI, MALUKU, atau PAPUA. Untuk data lama, sinkronkan npulau dari tabel master kawasan berdasarkan nupt dan nkws.

update public.reports r
set npulau = k.npulau,
    kawasan_id = k.id
from public.kawasan k
where lower(trim(r.nkws)) = lower(trim(k.nkws))
  and lower(trim(r.nupt)) = lower(trim(k.nupt));

Konfigurasi koneksi

Isi SUPABASE_URL dan SUPABASE_KEY di bagian awal JavaScript. Gunakan publishable/anon key, bukan service role key. Jika RLS aktif dan aplikasi belum login, policy SELECT untuk role anon diperlukan agar dashboard dapat membaca data.

create policy "anon read reports"
on public.reports for select
to anon using (true);
