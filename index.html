DOKUMENTASI TEKNIS

Supabase, Data Backend & Deployment

Panduan konfigurasi database produksi, keamanan, dan publikasi frontend.

1. Skema tabel Supabase

Buka Supabase SQL Editor dan jalankan skema berikut. Aktifkan Row Level Security (RLS) lalu buat policy sesuai peran admin/operator organisasi Anda.

create table public.reports (
  id uuid primary key default gen_random_uuid(),
  tanggal date not null,
  npulau text not null,
  nupt text not null,
  nkws text not null,
  status text not null check (status in (
    'Upaya Pemadaman', 'Proses Groundcheck',
    'Sudah Padam', 'Perlu Konfirmasi', 'False Hotspot'
  )),
  lat double precision not null,
  lon double precision not null,
  luas numeric default 0,
  upaya text,
  rencana text,
  personel text,
  kendala text,
  kebutuhan text,
  created_at timestamptz default now(),
  updated_at timestamptz default now()
);

alter table public.reports enable row level security;

-- Contoh policy sederhana:
create policy "authenticated can read reports"
on public.reports for select to authenticated using (true);
create policy "authenticated can insert reports"
on public.reports for insert to authenticated with check (true);
create policy "authenticated can update reports"
on public.reports for update to authenticated using (true);
create policy "authenticated can delete reports"
on public.reports for delete to authenticated using (true);

2. Konfigurasi frontend

  1. 1. Buat project baru di Supabase dan salin Project URL serta anon/publishable key dari Project Settings → API.
  2. 2. Masukkan nilainya pada konstanta SUPABASE_URL dan SUPABASE_ANON_KEY di bagian konfigurasi skrip HTML.
  3. 3. Jangan pernah menaruh service_role key pada HTML/frontend publik.
  4. 4. Untuk penggunaan produksi, aktifkan Supabase Auth serta policy RLS berbasis peran agar hanya petugas berwenang dapat membuat, mengubah, dan menghapus laporan.
  5. 5. Tambahkan tabel spasial/kawasan dan proses ETL administratif di backend bila peta batas kawasan diperlukan.
Perubahan pengelolaan data: impor data historis CSV dan data spasial/GeoJSON tidak lagi tersedia dari UI ini. Admin harus memvalidasi, memigrasikan, dan mengimpor data tersebut secara manual langsung melalui database/backend yang dibangun.

3. Deploy gratis

GitHub Pages

Simpan aplikasi sebagai index.html, push ke repository, lalu aktifkan Settings → Pages → Deploy from branch main / root.

Netlify

Hubungkan repository GitHub atau upload folder berisi index.html. Netlify menerbitkan HTTPS otomatis.

Vercel

Import repository, gunakan preset static/Other, tanpa build command, kemudian Deploy.
